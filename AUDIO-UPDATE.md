# Castle Chaos Audio v1.2

Original synthesized soundtrack and sound effects. No third-party samples or copyrighted television-show audio.

## Deploy
Upload the updated project files to your existing GitHub repository, preserving the `public/` directory. The new file `public/audio.js` is essential. Commit the changes and check that Render deploys the new commit. Your existing URL remains unchanged.

## Test
Open the website, click Create Room, and listen for the lobby soundtrack. Roll a die, play a mini-game, adjust music and effects sliders, mute/unmute, and reload to check settings persistence. Repeat on a phone. Browser autoplay rules require initial interaction.

## Scope
This is a client-side audio-only feature. Multiplayer game rules and security v1.1 server code are unchanged.
