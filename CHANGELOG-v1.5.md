# Castle Chaos v1.5

- Lobby host can select Random Shuffle or Host Chooses.
- Random Shuffle runs all seven games in a random order before reshuffling, avoiding immediate repeats.
- Host Chooses pauses after all dice rolls, then offers seven game buttons to the host.
- Distinct procedurally generated music for the lobby, board, seven mini-games, results, and finale.
- No new dependencies or hosting configuration needed.

After deploying, start a NEW room to see the game mode controls. Existing rooms will end when Render restarts.
