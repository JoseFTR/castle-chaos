# Castle Chaos v1.9 — Language Settings

- Added an always-visible language selector to every screen.
- English, Brazilian Portuguese (Português do Brasil), Spanish, and Japanese.
- Language preference is saved locally per device.
- Game mechanics, multiplayer messages, scoring, security controls, and audio are unchanged.
- UI text, game names, instructions, score labels, and common server notices are translated in the browser.
- Player-created nicknames and room codes remain unchanged.
- Translations are an initial localization pass and should be reviewed by native speakers.
